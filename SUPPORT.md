# Support

- **Questions and bugs:** open an issue on [php-io-extensions/raven](https://github.com/php-io-extensions/raven/issues). Include `php --ri raven`, your OS, PHP version and build (NTS or ZTS), the backend you initialised, and the smallest script that shows the problem.
- **How a Raven call behaves:** [Raven's documentation](https://oscar-soirey.github.io/Raven/) and the comments in [`lib/raven/include/raven/`](lib/raven/include/raven) are the reference; this extension adds only what the README's API section describes.
- **Security problems:** see [SECURITY.md](SECURITY.md); do not open a public issue.
